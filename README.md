 Project Description

This is my personal portfolio website, developed as a Grade 12 school project using HTML, CSS, PHP, and MySQL.

The website introduces me, showcases my skills and projects, and allows visitors to contact me through a contact form.

🎯 Project Objectives

Introduce myself and my interests.

Showcase my technical skills.

Display my projects.

Allow visitors to send messages.

Store visitor messages in a MySQL database.

Provide an administrator login to view submitted messages
